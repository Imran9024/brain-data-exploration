# Phase-II Project Plan

## Work packages
1. Requirements review against Phase-I objectives.
2. System architecture and user-flow design.
3. Browser dashboard implementation.
4. CSV data loading and validation.
5. Signal visualization and interactive filtering.
6. Descriptive statistics and correlation visualization.
7. Functional testing with synthetic data.
8. Testing with an appropriately licensed real research dataset.
9. Capture genuine screenshots, document findings, and prepare the evaluation demo.

## Suggested evaluation demo
1. Introduce the Phase-I objectives and Phase-II scope.
2. Show the architecture diagram and explain the browser-only data flow.
3. Open `app/index.html` in a modern browser.
4. Demonstrate the bundled synthetic data first.
5. Upload a valid CSV and show channel selection, sample window, statistics and correlation.
6. Explain limitations and the plan for real-data evaluation.
7. Record supervisor feedback and update the report.

## Scope discipline
Do not state that the project supports full MRI/fMRI/MEG/DTI processing until those workflows are implemented and tested. The current runnable prototype focuses on numeric multi-channel time-series CSV data.
